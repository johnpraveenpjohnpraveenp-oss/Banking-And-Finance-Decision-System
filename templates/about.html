ML Pipeline Architecture

1

Data Generation

2,500+ synthetic but realistic loan applicant records generated using banking credit-risk rules with NumPy distributions.

2

Preprocessing

StandardScaler for numeric features (Age, Income, Credit Score, Loan Amount, Loan Term). OneHotEncoder for categorical features (Employment, Education, Self-Employed).

3

Random Forest

Ensemble of 150 decision trees with max_depth=15. Aggregates predictions via majority voting for robust, high-accuracy outcomes.

4

Evaluation

Tested on 20% holdout set. Metrics: Accuracy, Precision, Recall, F1-Score, Confusion Matrix, and Classification Report.
